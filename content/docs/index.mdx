## 建议学习顺序

1. **模块 ③ 的前两课**（Actions 概念 + 第一条流水线）——先给项目装上「安全网」，这是后面所有协作的前提。
2. **模块 ①②**（Issue + PR）——把想法变成可追踪的任务，再用 PR 闭环把它合并进去。
3. **模块 ③ 剩余**（触发器、secrets、自动部署）——一个人也能把产品 ship 上线。
4. **模块 ④**——把这套实践变成团队规范：保护分支、required checks、CODEOWNERS。

<Callout type="warn">
**这是「GitHub 课」不是「git 课」。** 如果你想知道 `git rebase` 怎么写，那不是本课重点；
本课讲的是：当代码到了 GitHub，你能用它做什么。第 ② 模块第一节会专门帮你划清这条界线。
</Callout>
